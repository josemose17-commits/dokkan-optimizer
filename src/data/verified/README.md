# Future verified data

Intentionally empty. No real card data is bundled or fetched at runtime.

Read [the data-source review](../../../docs/DATA_SOURCES.md) before adding an adapter or dataset. Verify access/reuse terms first. Keep records here separate from `../fixtures/` and retain stable internal/source IDs, source URLs/revisions, reuse terms, review and verification dates, region/language, awakening state, and supported/unsupported mechanics.

`Provenance` reserves a `verified` kind, but the current reference evaluator accepts only `synthetic` records with a null `verifiedAt`. A future verified combat evaluator must have its own reviewed assumptions and independent correctness examples. Do not relabel fixture ratings as real stats.
