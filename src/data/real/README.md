# Reviewed real facts, not a globally verified dataset

The six orb records and exact EZA Goku profile are a manually normalized, limited snapshot. They have field-level source evidence and explicit null independent-verification dates. The `real` directory name distinguishes them from fictional fixtures; it does not claim independent verification.

Read [the evidence ledger](../../../docs/character-build/EVIDENCE.md) and [access assessment](../../../docs/character-build/DATA_ACCESS.md). Source documentation, independent confirmation of game behavior, and mathematical test success are separate statuses. No artwork, expressive card text, scraped dataset, runtime endpoint or synthetic performance rating is included.

The fully activated 55% no-dupe profile is the only admitted progression. Never expand it into guessed node options or allow arbitrary level sliders. Re-review facts and permissions before expanding this catalog. New records require stable internal IDs, source aliases when actually known, exact region/state, field evidence, review/verification dates and support declarations.
