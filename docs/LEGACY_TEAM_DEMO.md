# Retired synthetic team demonstration

The synthetic team app, engine, fixtures, styles and demo-only tests were removed from the production product after the approved project reset. Git history before this change preserves them. Old `?workbench=legacy-team` URLs intentionally return to the character workspace with a retirement message.

The obsolete local key `dokkan-team-lab.collection.v1` is neither read nor deleted. No automatic storage cleanup or migration occurs. Historical synthetic scores are not character-performance formulas.
