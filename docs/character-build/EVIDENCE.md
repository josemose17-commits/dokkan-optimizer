## Three separate kinds of confidence

- **Documented:** a named source states the rule/value. Agreement among databases with unknown upstream provenance remains documented, not independent confirmation.
- **Independently corroborated:** a genuinely independent observation/extraction or controlled in-game record confirms the fact. No field in this snapshot is assigned this status; `verifiedAt` is null. Two sites repeating a game table do not establish independence.
- **Mathematically tested:** implementation matches independent arithmetic/enumeration oracles. This is recorded separately and never upgrades mechanics evidence.

Sources are unofficial unless explicitly described otherwise. Search-index excerpts were used when normal page retrieval failed; they are weaker evidence and are identified below. There is no claim that this snapshot is independently verified in-game.

## Exact exposed formulas

For the supported profile, `stats = cardBase + 2800 + flatEquipStats`; `A = 5 + equipAA`, `C = equipCritical`, `E = equipEvasion`. Initial AA trigger is `.02*A`; initial check followed by an extra Super is `.02*A*.5`; per eligible attack critical is `.02*C`; evasion is `.01*E` if the context assumes it is allowed, otherwise 0. The latter is an explicit context input, not a verified description of a named enemy. No probability is extended outside the admitted levels/catalog. Missing metrics use `null` plus an explanation, never 0.

The context fixes battle turn 1, first appearance, initial Super available, no external effects, and no native stochastic/stacking effects. Leaders, links, support, enemy DEF, debuffs and combat multipliers have no effect on the exposed **card stats**; battle stats and damage are not computed. These exclusions are displayed, not silently ignored.

Independent passive-combination probability arithmetic and hypothetical damage branches occur only in tests. They do not establish game behavior or add support for complex kits.
